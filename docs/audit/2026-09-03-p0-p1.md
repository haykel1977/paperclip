## Issue description (inline — no closing GitHub issue)

This change is not attached to a backlog issue that should auto-close.

### What happened?

On `main` @ `ca53c5f`, the HTTP adapter fetched operator-controlled URLs with no SSRF guard; `DELETE /agents/:id` 500'd when `cost_events` existed and left ghost assignees; isolated-workspace issue fields were silently dropped when `enableIsolatedWorkspaces` was false; OpenCode could mkdir `/Users` from a Darwin HOME overlay on Linux; Recovery no-op-done skip from PR 98 stayed opt-in so `successful_run_missing_state` loops could continue.

### Expected behavior

Public-only HTTP adapter fetches by default; agent hard-delete succeeds and clears assignees; isolated workspace writes return 422 when the experimental flag is off; OpenCode home resolution stays on a writable Linux path; no-op-done skip is on unless explicitly disabled; `PAPERCLIP_ALLOW_CLOUD_MODELS` remains fail-closed.

### Steps to reproduce

1. Point an `http` adapter at `http://127.0.0.1/` and invoke a run (SSRF).
2. Insert a `cost_events` row for an agent, then `DELETE /api/agents/:id`.
3. With `enableIsolatedWorkspaces=false`, PATCH an issue with `executionWorkspacePreference=isolated_workspace` and observe a 200 that did not persist (fixed to 422).
4. Set `HOME=/Users/someone` on Linux and inject OpenCode skills.

`ca53c5f0` (`haykel1977/paperclip` main before this PR).

Self-hosted / local source tree. Live Kantum hosts were not queried.

### Suivi revue Copilot (PR 101)

Confirmé et corrigé dans le même PR (pas de relâchement sécu) :

1. **Redirect SSRF** — `fetch` ne suit plus les 30x (`redirect: "manual"`) ; un 3xx / `opaqueredirect` est une erreur `http_url_ssrf_blocked`, pas un warn de connectivité.
2. **422 workspace + `null`** — `undefined` **et** `null` ne comptent pas comme « champ fourni » (Zod autorise le clear). Le 422 ne vise que `isolated_workspace` / `operator_branch` : `reuse_existing` et le linkage shared restent valides (heartbeat setup).
3. **DELETE agent FKs issues** — deux `UPDATE` séparés : seul le FK qui matche l’agent est nullé (`assigneeAgentId` vs `createdByAgentId`).
4. **Flag no-op-done inconnu** — unset → ON ; seulement `1`/`true`/`yes`/`on` restent ON ; `maybe`/`disable`/autres → OFF.
5. **DNS pin (Bugbot)** — le connect TCP utilise l’IP déjà contrôlée (`lookup` custom) ; Host/SNI restent le hostname d’origine. Pas de nouvelle dépendance.
6. **OpenCode home (Bugbot)** — ordre par défaut : passwd (`userInfo`) puis `HOME` puis `os.homedir()`. `skills` honore un `env.HOME` explicite en premier. Le skip `/Users` sur Linux reste.
7. **Timeout piné (Bugbot)** — `http.request({ signal })` ; abort → `AbortError` pour que `execute` mappe encore `timedOut`.
8. **Userinfo piné (Bugbot)** — `user:pass@host` est recopié en `auth` / Basic (sauf si `Authorization` est déjà fourni). `decodeURIComponent` est try/catch : un `%` littéral (WHATWG) ne casse plus le webhook.
